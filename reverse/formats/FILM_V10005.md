# Replay film format v10005

Status: **partially confirmed / actively reconstructed**.

The four canonical PAK demos and eleven additional `Perfect_Demos` recordings are all exactly **40,296 bytes** and begin with big-endian format version **10005**.

## Proven/strong layout

| Offset | Size | Current interpretation |
| ---: | ---: | --- |
| `0x00` | 4 | BE format version, `10005` |
| `0x04` | 4 | unknown field; preserved raw |
| `0x08` | 4 | FourCC level-related ID A |
| `0x0c` | 1 | mode byte; `1` in all current one-player evidence |
| `0x0d` | 3 | zero in current corpus |
| `0x10` | 4 | BE recorded input tick count |
| `0x14` | 4 | unknown field; preserved raw |
| `0x18` | 4 | FourCC level-related ID B |
| `0x1c`..`0x3f` | 36 | zero in current corpus |
| `0x40` | 20,000 | first observed input-mask stream capacity |

The tick count interpretation is strongly supported because every film's first input stream becomes zero after the declared tick and remains zero through the 20,000-byte capacity. One supplied film declares exactly 20,000 ticks, independently confirming the capacity boundary.

The file-size arithmetic supports a **candidate** player-record stride of 20,116 bytes after the 64-byte global header (`64 + 2*20116 = 40296`). In current one-player films the second candidate record is zero. The 116-byte first-player tail contains `none` at tail offsets 100..103 in all fifteen analyzed films; its semantics remain unknown.

## Input masks

One byte is observed per recorded tick. Only bits 0..6 occur; bit 7 is absent across **135,840** active ticks.

Corpus counts:

- bit 0: 32,003
- bit 1: 32,219
- bit 2: 21,961
- bit 3: 27,945
- bit 4: 12,619
- bit 5: 81,365
- bit 6: 109
- bit 7: 0

Bits 2 and 3 never co-occur; bits 0 and 1 co-occur only 56 times. These two pairs are therefore strong candidates for opposing directional axes. Bit 6 is rare and is consistent with the documented weapon-switch action, but the clean API intentionally leaves exact action names unassigned until PPC or controlled two-player evidence proves them.

The Perfect Demos read-me documents the recorder's seven controls as up/down/left/right, air weapon, ground weapon, and weapon switching. That proves the action set but not yet the bit-to-action permutation.
